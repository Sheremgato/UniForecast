Методология исследования

Как подготовлены данные и проверено качество

01

Синтетические заявки

Смоделированы записи по пяти подразделениям с календарной сезонностью и случайными колебаниями.

02

Временные ряды

Записи сгруппированы по дням. Пропущенные календарные дни заполнены нулём.

03

Обучение MLP

Для прогноза используются календарные признаки (месяц, день недели, циклический день года) и код подразделения — без прошлых значений нагрузки.

04

Честная оценка

Временное разбиение train/validation/test, нормализация только по train, сравнение с baseline.
